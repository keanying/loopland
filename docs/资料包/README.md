## 说明

- 底部导航是悬浮弧形长条，中间是会跑的「闪电壁虎」开始按钮；AI 跟练页用浅色版。
- 登录页背景视频右下角有一个小水印，正式上线前建议换成可商用、无水印的素材。

- 离线原型用的是电脑自带字体，和线上画布相比字体可能略有差别。
- 原型里的用户、跑团、商户、订单都是示意数据；商户名称是虚构的。
- 「loopland」字标使用 Lexend Bold，包里暂无字标的矢量文件，需要时可用该字体导出。
- App 内 AI 助手目前仍叫「圈圈」，和 App 同名，建议改为「小圈」，待确认。
- 商标、域名、应用商店名称在正式使用前需要逐一查询注册。
