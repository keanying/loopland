# 圈圈 Loopland · 图标文件

标志：方向 B · 双环 oo。空心圈是跑步路线，实心圈是圈下的地，紫点是正在跑的人。

## 文件

| 文件夹 | 内容 | 用在哪 |
| --- | --- | --- |
| SVG/ | 全部矢量源文件 | 设计改稿、任意尺寸导出 |
| iOS/ | AppStore_1024.png 和 20–180 px 各尺寸，方形不带圆角 | Xcode 的 AppIcon，系统会自动裁圆角 |
| Android/ | GooglePlay_512.png、各密度 ic_launcher，以及 adaptive 的前景层和背景层 | Android 启动图标、应用商店 |
| 网页/ | favicon 16–512、apple-touch-icon | 官网、管理端浏览器标签 |
| 品牌预览/ | 深色、浅色、绿色三种底的图标，以及透明底的标志（含黑白单色版） | 海报、PPT、物料 |

## 颜色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 夜跑黑 | #0E0E10 | 主背景 |
| 荧光绿 | #DCF26A | 实心圈、主按钮 |
| 薰衣紫 | #B4A3F5 | 跑者圆点、点缀 |
| 纯白 | #FFFFFF | 深色底上的空心圈 |
| 墨黑 | #141414 | 浅色底上的空心圈 |

## 字体

- 英文字标 loopland：Lexend Bold，字距 -4%，全小写，两个 o 换成双环图形
- 中文名 圈圈：思源黑体（Noto Sans SC）Black
- 两款字体都是开源字体（SIL OFL），可免费商用

## 使用规则

- 标志四周至少留出一个实心圈半径的空白
- 小于 24 px 时去掉紫色圆点，只保留双环
- 不要拉伸、旋转、加阴影或描边，也不要改颜色顺序（空心在左，实心在右）
