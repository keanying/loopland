# 系统配置 · 第三方服务（管理端）

管理端「系统配置」页面维护第三方服务的 Key：阿里云账号、短信、人机验证、一键登录、实名核验、微信登录、微信支付、支付宝、Apple、AI 大模型、邮件、高德 Web 服务、对象存储 OSS。

- **权限**：只有 `admin` 角色可以查看和修改；其他角色返回 403 `forbidden`。
- **存储**：`src.src_sys_loop_provider_config`。敏感字段用 `LOOPLAND_DATA_KEY` 做 AES-256-GCM 加密后存库，接口**永远不返回明文**。
- **优先级**：管理端保存过的服务以数据库为准；没保存过的继续用 `server/config.yaml` / 环境变量（`source` 字段区分）。第一次保存会把当前生效值连同修改一起写入数据库。
- **生效**：保存后本实例立即生效，其他实例 30 秒内生效，不用重启。
- **审计**：保存和测试都记审计日志（`provider.save` / `provider.test`），只记字段名，不记值。

所有接口需要管理端 Token：`Authorization: Bearer <admin token>`。

## GET /admin/v1/providers

列出全部服务（按展示顺序），包含表单定义和当前值。

```json
{
  "items": [
    {
      "code": "ai",
      "name": "AI 大模型",
      "group": "AI",
      "description": "国内已备案大模型的 OpenAI 兼容接口……",
      "fields": [
        {"key": "vendor", "label": "厂商", "kind": "select", "secret": false, "required": true,
         "options": ["qwen", "deepseek", "doubao", "zhipu", "custom"], "default": "qwen", "help": "qwen-通义千问 ……"},
        {"key": "api_key", "label": "API Key", "kind": "text", "secret": true, "required": true}
      ],
      "enabled": true,
      "configured": true,
      "source": "db",
      "values": {
        "vendor": "qwen",
        "model": "qwen-plus",
        "api_key": {"set": true, "hint": "sk****56"}
      },
      "last_check": {"status": "ok", "message": "连接正常", "time": "2026-11-21T10:00:00+08:00"},
      "updated_by": 1,
      "update_time": "2026-11-21T09:58:00+08:00"
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `group` | 分组：账号与安全 / 支付 / AI / 通知 / 地图 / 存储 |
| `uses` | 可选（为空时不返回）。复用哪个服务的凭证（如短信复用 `aliyun`）；该服务没配好时不能启用 |
| `test_input` | 可选（为空时不返回）。有值时，测试前需要额外输入（文案即提示语，如「测试手机号」） |
| `fields` | 表单字段，没有字段的服务（一键登录、实名核验只需启用）为空数组 `[]`；`help`、`options`、`default` 为空时不返回 |
| `fields[].kind` | `text` 单行 / `textarea` 多行（证书、私钥） / `number` 整数 / `bool` 开关（值为 `"true"`/`"false"`） / `select` 下拉（`options`） / `url` 地址 |
| `fields[].secret` | 敏感字段：`values` 里只给 `{set, hint}`，不给明文 |
| `enabled` | 当前是否启用 |
| `configured` | 必填项（以及 `uses` 的服务）是否填全 |
| `source` | `db`-管理端保存的 `config`-来自配置文件/环境变量 `none`-未配置 |
| `values` | 非敏感字段为字符串（含默认值）；敏感字段为 `{"set": bool, "hint": "前2位****后2位"}` |
| `last_check` | 最近一次测试；没测过为 `null`。`status`：`ok`-通过 `fail`-失败 |
| `updated_by` / `update_time` | 最后一次在管理端保存的管理员和时间；没保存过为 `null` |

## PUT /admin/v1/providers/{code}

保存一个服务的配置。

```json
{
  "enabled": true,
  "values": {"model": "qwen-max", "api_key": ""},
  "clear": ["small_model"]
}
```

- `values` 只需要传改动的字段；没传的字段保持原值。
- 敏感字段传空字符串 = **保持原值**（表单里留空即不修改）。
- `clear` 列出要清空的字段（用于删除一个敏感值）。
- `enabled: true` 时校验必填项和 `uses` 的服务；`enabled: false` 可以保存不完整的配置。

返回保存后的这一项（格式同列表里的一个元素）。

错误：

| 状态 | code | 场景 |
| --- | --- | --- |
| 400 | `invalid_config` | 未知字段、整数/开关/下拉/地址格式不对、启用时必填项没填（message 列出缺的字段名）、依赖的服务没配置 |
| 404 | `not_found` | 没有这个服务 |

## POST /admin/v1/providers/{code}/test

用**当前生效的配置**做一次连通测试，并记录结果。测试不会改变配置来源。

请求体可选：`{"input": "13800000000"}`（服务有 `test_input` 时填写）。

| 服务 | 测试做什么 |
| --- | --- |
| aliyun / oneclick | 调一次号码认证查询接口，验证 AccessKey |
| sms | 验证 AccessKey 和签名；填了测试手机号时真实发送一条（验证码 123456） |
| captcha | 验证 AccessKey 和场景 |
| realname | 必须填「姓名,身份证号」，会产生一次收费调用 |
| wechat_login | 用假 code 换 token，验证 AppID/AppSecret |
| wechat_pay / alipay | 查询一个不存在的订单，验证商户号、证书和密钥 |
| apple | 下载 Apple 公钥 |
| ai | 发一个 1 token 的对话请求，验证地址、Key、模型 |
| email | 必须填收件邮箱，真实发送一封测试邮件 |
| amap | 调一次 IP 定位接口验证 Key |
| oss | 往 Bucket 写一个 `_loopland/check.txt`，验证地域、Bucket、AccessKey 和上传权限 |

返回：

```json
{"status": "fail", "message": "HTTP 401 invalid api key", "time": "2026-11-21T10:00:00+08:00"}
```

测试失败也返回 200（结果在 `status` 里）；只有服务不存在返回 404。

## 对 App 的影响：GET /v1/config/features

保存后立即反映到 App 的功能开关：

```json
{"login": ["apple", "oneclick", "sms", "wechat"], "pay": ["alipay_app", "apple_iap", "wechat_app"], "captcha": true, "ai": false}
```

`ai` 为新增字段：AI 大模型已启用时为 `true`。dev 环境下没配置的登录/支付方式用假实现代替，所以仍会出现在列表里；同样，dev 环境没配置 AI 大模型时用内置的「开发环境模拟 AI」，`ai` 也为 `true`。

AI 大模型（第三批）新增可选字段：`vision_model`（视觉模型，空 = 不支持图片）、`price_input_per_mtok_fen` / `price_output_per_mtok_fen`（每百万 Token 单价，单位分，只用于管理端「AI 用量」估算费用）。`small_model` 用于战报、路线解释和审核打分。
