# 圈圈 Loopland · V1 API 约定

App 用 `/v1`，管理端用 `/admin/v1`。本文件是前后端共同的约定，后端实现必须与之一致，改动需同步更新本文件。

## V1 范围

| 进 V1 | 放到 V2 |
| --- | --- |
| 登录注册（短信、一键登录、微信、Apple）、隐私授权、实名与年龄、注销冷静期、数据导出 | 动态流、评论、发布、轨迹回放、他人主页、私信 |
| GPS 运动记录与上传、居家训练（力量、瑜伽、跳绳、HIIT）计时换能量 | 场馆签到与馆主、组局、赛事 |
| 自由圈地、抢地判定、风控（自动作废 / 人工复核）、领地回滚 | 城市怪兽 Boss、宝箱、赛季与联赛、限时活动 |
| 领地地图（视野加载）、建城、角色驻扎、每日产能 | AI 助手与 AI 跟练、语音播报 |
| 图鉴：角色招募、建筑解锁、伙伴蛋孵化、里程奖牌 | 商户、联名、能量商城、场馆预订 |
| 跑团：创建、加入/申请、退出、踢人、转让、团内排行 | 推送（个推/极光）、手表接入 |
| 会员：套餐、下单（微信、支付宝、Apple 内购）、回调、自动续费开关、退款 | 内容审核、商户与活动（管理端） |
| 站内消息（领地被抢、被削弱、系统） |  |
| 管理端：总览、用户、套餐与订单、地图与领地、风控、玩法配置、审计、后台账号 |  |

## 通用约定

- JSON，UTF-8。时间是 RFC3339 字符串（带时区）。金额单位是**分**（整数）。距离单位米，面积单位平方米。
- 坐标一律 **GCJ-02**（高德坐标），对象写成 `{"lat":31.23,"lng":121.47}`；GeoJSON 里按 `[lng, lat]`。
- 鉴权：`Authorization: Bearer <access_token>`。App 和管理端的 token 互不通用。
- 分页：`?page=1&page_size=20`（page_size 最大 100），返回 `{"items":[...],"total":123}`。
- 错误：HTTP 状态码 + `{"error":{"code":"not_enough_energy","message":"需要 120，当前 80"}}`。`code` 是稳定的英文常量，`message` 可直接展示。
  - 通用 code：`invalid_body` 400、`unauthorized` 401、`forbidden` 403、`not_found` 404、`conflict` 409、`rate_limited` 429、`internal` 500。
- 开发环境（`LOOPLAND_ENV=dev`）：短信验证码固定 `000000`，支付可用 `mock` 渠道，并开放 `/v1/dev/*` 接口。

## App · 账号

### POST /v1/auth/sms/send
`{"phone":"13800138000","captcha_token":"..."}` → `{"cooldown_s":60}`

同号 60 秒 1 次、每天 10 次；同 IP 每小时 30 次。超限返回 `rate_limited`。

### POST /v1/auth/login
```json
{
  "provider": "sms | oneclick | wechat | apple",
  "credential": { },
  "device_id": "uuid",
  "platform": "ios | android"
}
```
credential：
- sms：`{"phone":"138...","code":"123456"}`
- oneclick：`{"token":"运营商 token"}`
- wechat：`{"code":"微信 SDK 返回的 code"}`
- apple：`{"identity_token":"JWT","nickname":"可选"}`

返回 `AuthResult`：
```json
{
  "access_token": "...", "refresh_token": "...", "expires_in": 7200,
  "is_new": true,
  "need_bind_phone": false,
  "user": { User }
}
```
微信、Apple 首次登录 `need_bind_phone=true`，客户端必须引导绑定手机号（调 `/v1/me/phone`）后才能使用其他接口，否则其他接口返回 403 `phone_required`。

错误 code：`invalid_phone`、`invalid_code`、`code_expired`、`provider_error`、`account_banned`（可能带 `banned_until`）。

注销冷静期内的账号可以正常登录，返回的 `user.status` 为 `deleting`、`delete_after` 有值，客户端应提示「账号注销中」并提供撤回按钮（`DELETE /v1/me/deletion`）。

### POST /v1/auth/refresh
`{"refresh_token":"..."}` → `AuthResult`（refresh token 轮换，旧的立即失效）

### POST /v1/auth/logout
`{"refresh_token":"..."}` → `{}`

```json
{

  "consents": { "privacy_version": "2026-11", "location": true, "health": false },

  "created_at": "..."

```
`crew`、`membership` 没有时为 `null`。未成年（`is_adult=false`）时客户端不展示任何付费入口，服务端也会拒绝下单。

### GET /v1/me → `User`
### PATCH /v1/me
`{"nickname":"...","avatar_url":"...","settings":{...部分字段}}` → `User`

### POST /v1/me/phone
绑定手机号：`{"phone":"...","code":"..."}` 或 `{"oneclick_token":"..."}` → `User`。手机号已被别的账号使用时返回 409 `phone_taken`。

### POST /v1/me/consents
`{"privacy_version":"2026-11","location":true,"health":true}` → `User`。没有同意隐私政策（`privacy_version` 为空）时，运动上传返回 403 `consent_required`。

### POST /v1/me/realname
`{"name":"张三","id_number":"..."}` → `User`（`realname_verified`、`is_adult` 更新）。服务端只保存是否成年和出生年份，不保存身份证号。错误：`realname_failed`。

### POST /v1/me/deletion → `{"delete_after":"..."}`（7 天冷静期）
### DELETE /v1/me/deletion → `User`（撤回注销）
到期后删除轨迹和个人信息，名下领地变为无主。

### GET /v1/me/export
返回 JSON 文件：账号资料、运动记录（含轨迹）、领地、图鉴、订单。

## App · 运动

### POST /v1/activities
上传一次运动（结束后一次性上传）。`client_id` 是客户端生成的 UUID，重复上传返回同一结果（幂等）。
```json
{
  "client_id": "uuid",
  "sport": "run",
  "started_at": "...", "ended_at": "...",
  "duration_s": 1800,
  "goal": { "type": "free | distance | time | target", "value": 5000, "territory_id": 12 },
  "points": [ { "t": 1732000000000, "lat": 31.23, "lng": 121.47, "acc": 5, "spd": 2.9, "hr": 150, "cad": 170, "src": "gps | network | mock" } ],
  "amount": 30,
  "device": { "id": "uuid", "model": "iPhone15,2", "os": "iOS 18.1", "rooted": false, "emulator": false, "multi_open": false },
  "wearable": { "brand": "apple | huawei | garmin | coros" }
}
```
- GPS 运动必须有 `points`（`t` 是毫秒时间戳，升序），`amount` 忽略，距离由服务端计算。
- 居家运动没有 `points`，`amount` 按该运动的 unit 填（力量、瑜伽、HIIT 是分钟，跳绳是次数）。
- 最多 20000 个点。
- V1 可上传的 sport：`run` `ride` `hike` `walk` `strength` `yoga` `rope` `hiit`，其他返回 400 `sport_not_supported`。
- 被封禁的账号所有需要登录的接口都返回 403 `account_banned`。

返回 `ActivityResult`：
```json
{
  "activity": { Activity },
  "settlement": {
    "status": "settled | review | voided",
    "energy_raw": 53,
    "energy_granted": 53,
    "energy_capped": false,
    "claims": [ { "territory_id": 101, "kind": "claim | capture", "area_m2": 5230.5 } ],
    "attacks": [ { "territory_id": 88, "owner": { "id": 7, "nickname": "..." }, "captured": false, "guard_before": 120, "guard_after": 67, "area_m2": 900 } ],
    "recruits": [ { "role": "archer", "name": "弓箭手", "progress": 12.4, "threshold": 30, "unit": "km", "recruited": false } ],
    "eggs": [ { "key": "gecko", "name": "闪电壁虎", "progress_km": 3.6, "hatch_km": 10, "hatched": false } ],
    "medals": [ { "key": "distance_100", "name": "百公里" } ],
    "level_up": null,
    "flags": [ { "rule": "speed", "detail": "平均速度 24.3 km/h 超过跑步上限 20" } ]
  }
}
```
- `review`：疑似作弊，进入人工复核；不发能量、不圈地，复核通过后再结算并发站内信。
- `voided`：确定作弊，作废。
- 新用户第一次圈到地时额外得到一颗「闪电壁虎」蛋。

### GET /v1/activities?page= → `{"items":[Activity],"total":n}`（不含轨迹）
### GET /v1/activities/{id} → `Activity`（含 `track`、`claims`）

Activity：
```json
{
  "id": 1, "sport": "run", "status": "settled",
  "started_at": "...", "ended_at": "...",
  "distance_m": 5370, "duration_s": 1800, "avg_pace_s_per_km": 335,
  "amount": 5.37, "energy_granted": 53, "claimed_area_m2": 5230.5,
  "track": { "type": "LineString", "coordinates": [[121.47, 31.23]] },
  "claims": [ { "territory_id": 101, "kind": "claim", "area_m2": 5230.5 } ]
}
```

### POST /v1/claims/preview
跑步中预览（可选，客户端也可以本地算）：`{"sport":"run","points":[{"lat":..,"lng":..}]}` →
`{"loops":[{"ring":[{lat,lng}],"area_m2":..,"perimeter_m":..,"closed_at":4}],"total_area_m2":..,"discarded":0,"hint":{"distance_m":120,"target":{lat,lng}},"distance_km":1.2,"raw_energy":12}`

## App · 会员与支付

### GET /v1/plans → `{"items":[Plan],"minor_blocked":false}`
未成年用户 `items` 为空、`minor_blocked=true`。
```json
{
  "code": "auto_month", "name": "连续包月", "period": "month | quarter | year",
  "auto_renew": true, "price_fen": 1800, "first_price_fen": 1500, "renew_price_fen": 1800,

}
```
默认套餐：连续包月 `auto_month`（首期 ¥15，续费 ¥18）、月卡 `month` ¥18、季卡 `quarter` ¥45、年卡 `year` ¥168、跑团版 `crew_year` ¥298（5 人）。

### POST /v1/orders
`{"plan_code":"auto_month","channel":"wechat_app | alipay_app | apple_iap | mock"}` → 
```json
{ "order": { Order }, "pay_params": { } }
```
pay_params：
- wechat_app：`{"appid","partnerid","prepayid","package":"Sign=WXPay","noncestr","timestamp","sign"}`
- alipay_app：`{"order_string":"..."}`
- apple_iap：`{"product_id":"...","app_account_token":"uuid"}`（客户端发起内购时带上 appAccountToken）
- mock：`{}`（仅开发环境）

iOS 上只能用 `apple_iap`（请求头 `X-Platform: ios` 时其他渠道返回 400 `channel_not_allowed`）。错误：`realname_required`（下单前必须实名，403）、`minor_blocked`、`plan_off_sale`、`provider_error`。

### GET /v1/orders/{order_no} → `Order`
```json
{ "order_no": "LP20261120xxxx", "plan_code": "auto_month", "plan_name": "连续包月", "amount_fen": 1500, "channel": "wechat_app", "kind": "purchase | renewal", "status": "created | paid | refund_requested | refunded | closed | renew_failed", "created_at": "...", "paid_at": null }
```
客户端支付完成后轮询此接口直到 `paid`（以服务端回调为准）。

### POST /v1/iap/apple
`{"signed_transaction":"JWS"}` → `User`（校验苹果签名，按 appAccountToken 对上订单）

### GET /v1/membership → `User.membership`（无会员时 `{"active":false}`）
### POST /v1/membership/auto-renew `{"enabled":false}` → 同上
扣费前 5 天发站内信提醒；关闭后到期不再扣费。Apple 订阅的自动续费由用户在系统设置里关闭，此接口对 Apple 渠道返回 409 `manage_in_app_store`。

### 支付回调（渠道调用，客户端不用）
`POST /v1/pay/notify/wechat`、`POST /v1/pay/notify/alipay`、`POST /v1/pay/notify/apple`

### POST /v1/dev/orders/{order_no}/pay（仅开发环境）→ `Order`（模拟支付成功回调）

## 管理端

管理端 token 由 `/admin/v1/login` 签发。角色：`admin` 管理员、`ops` 运营、`reviewer` 审核员、`merchant` 商户对接。只有 admin 能发布玩法配置、退款、管理后台账号。所有写操作记审计日志。权限不足返回 403 `forbidden`。

### POST /admin/v1/login
`{"username":"admin","password":"..."}` → `{"token":"...","admin":{"id":1,"username":"admin","role":"admin"}}`
### GET /admin/v1/me → `{"id":1,"username":"admin","role":"admin"}`

### 用户
- `GET /admin/v1/users/stats` → `{"total":1000,"today_new":20,"retention_7d":0.41,"members":50,"sources":[{"provider":"sms","count":600}]}`（sources 为近 30 天注册来源）
- `GET /admin/v1/users?q=&filter=all|member|today|abnormal&page=` → `{"items":[{"id","nickname","phone_masked","source","created_at","member":true,"status","delete_after"}],"total"}`。q 匹配昵称、ID、手机尾号（4 位）。abnormal = 有未处理风控告警或被禁言/封禁。
- `GET /admin/v1/users/{id}` → 用户详情：User 的字段加 `source`、`last_login_at`、`codex_count`、`risk_alerts:[RiskAlert]`
- `POST /admin/v1/users/{id}/reveal-phone` → `{"phone":"13800138000"}`（记审计）
- `POST /admin/v1/users/{id}/actions` `{"action":"gift_member_7d | notify | mute_7d | unmute | ban | unban","message":"notify 时必填"}` → 用户详情。封禁时冻结名下领地，解封时解冻。

### 套餐与订单
- `GET /admin/v1/entitlements` → `{"items":[{"key":"map_styles","name":"手绘 / 3D 地图","locked":false},{"key":"guard_bonus","name":"抢地守卫加成","locked":true},{"key":"extra_energy","name":"额外能量","locked":true}]}`
- `GET /admin/v1/plans` → `{"items":[Plan 加 "on_sale","sort"]}`
- `PUT /admin/v1/plans/{code}` `{"name","price_fen","first_price_fen","renew_price_fen","on_sale","recommended","sort"}` → Plan（改价只对新订单生效）
- `PUT /admin/v1/plans/{code}/entitlements` `{"entitlements":["map_styles"]}` → Plan（包含 locked 权益返回 400 `entitlement_locked`）
- `GET /admin/v1/orders?status=&q=&page=` → `{"items":[Order 加 "user":{"id","nickname"}],"total"}`
- `GET /admin/v1/orders/stats` → `{"month_revenue_fen":0,"active_members":0,"renew_success_rate":1.0,"refund_rate_today":0}`
- `POST /admin/v1/orders/{order_no}/refund` `{"reason":"...","confirm":true}` → Order（admin；原路退回并收回会员权益）
- `POST /admin/v1/orders/{order_no}/remind` → `{}`（续费失败提醒用户）

### 地图与领地
- `GET /admin/v1/territories?status=all|contested|frozen&q=&page=` → `{"items":[{"id","name","owner","crew","area_m2","guard","frozen","changes_today","building_count","center","updated_at"}],"total"}`。contested = 今天易手或被削弱过。
- `GET /admin/v1/territories/geo?bbox=` → `{"items":[TerritorySummary]}`（relation 固定 `unowned`/`enemy`，管理端按 owner 着色）
- `GET /admin/v1/territories/{id}` → Territory（含 `events` 全部记录，每条带 `kind`、`actor`、`prev_owner`、`new_owner`、`prev_guard`、`new_guard`、`admin`、`created_at`）
- `POST /admin/v1/territories/{id}/guard` `{"guard":500}`（0–2000，步长 50）→ Territory
- `POST /admin/v1/territories/{id}/freeze` `{"frozen":true}` → Territory
- `POST /admin/v1/territories/{id}/reset` → Territory（变为无主，建筑清空，通知原归属方）

### 风控
- `GET /admin/v1/risk/alerts?status=open|resolved&type=&page=` → `{"items":[RiskAlert],"total"}`，按置信度从高到低
  RiskAlert：`{"id","activity_id","user":{"id","nickname"},"type":"speed | mock_location | teleport | missing_device_data | multi_account | device_tamper","confidence":0.92,"detail":"...","status":"open | resolved","resolution":null,"created_at"}`
- `GET /admin/v1/risk/alerts/{id}` → 
  ```json
  { "alert": RiskAlert,
    "activity": Activity（含 track）,
    "speeds": [ { "t": 1732000000000, "kmh": 12.3, "over": false } ],
    "teleports": [ { "from": {lat,lng}, "to": {lat,lng}, "distance_m": 800, "gap_s": 3 } ],
    "device": { "id", "model", "os", "rooted", "emulator", "multi_open" },
    "sources": { "gps": 980, "network": 20, "mock": 0 },
    "cadence_avg": 168, "hr_avg": 150,
    "same_device_accounts": 1,
    "history": [RiskAlert] }
  ```
- `POST /admin/v1/risk/alerts/{id}/resolve` `{"action":"void | warn | ban_30d | false_positive","note":""}` → RiskAlert
  - void：作废运动，回滚它圈下和抢下的领地，扣回能量
  - false_positive：放行，补做结算（圈地、发能量）
- `GET /admin/v1/risk/rules` → `{"run_max_kmh":20,"ride_max_kmh":45,"hike_max_kmh":12,"walk_max_kmh":10,"teleport_m":500,"gap_s":30,"require_wearable_for_events":true}`
- `PUT /admin/v1/risk/rules` 同结构 → 同结构（只对新记录生效）

### 玩法配置
- `GET /admin/v1/gameplay` → `{"current":{"version","rollout_pct","body":Config,"note","published_at"},"previous":{...}|null,"history":[{"version","note","rollout_pct","published_by","published_at"}]}`
- `POST /admin/v1/gameplay/publish` `{"body":Config,"note":"...","rollout_pct":10}` → 同 GET（admin；body 校验失败返回 400 `invalid_config`，message 写明原因，比如掉落合计不是 100%）。rollout_pct 小于 100 时，按用户 ID 分桶，只有落在比例内的用户拿到新版本，其他人拿上一个全量版本。
- `POST /admin/v1/gameplay/rollout` `{"rollout_pct":100}` → 同 GET（把当前版本推到全量）
- `POST /admin/v1/gameplay/rollback` → 同 GET（撤回当前版本，回到上一个版本）

### 审计与账号
- `GET /admin/v1/audit?admin_id=&page=` → `{"items":[{"id","admin":{"id","username"},"action":"user.ban","target":"user:12","detail":{},"created_at"}],"total"}`
- `GET /admin/v1/admins` → `{"items":[{"id","username","role","disabled","created_at"}]}`（admin）
- `POST /admin/v1/admins` `{"username","password","role"}` → admin（admin）
- `PATCH /admin/v1/admins/{id}` `{"role"?,"disabled"?,"password"?}` → admin（admin）

登录失败返回 401 `invalid_credentials`。

首个管理员账号由环境变量 `LOOPLAND_BOOTSTRAP_ADMIN=用户名:密码` 在启动时创建（仅当没有任何管理员时）。
