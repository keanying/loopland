# 圈圈 Loopland · V2 第一批「玩法深化」API 约定

在 `docs/api/v1.md` 的基础上增加。通用约定（鉴权、错误格式、分页、坐标、时间）不变。

## 范围

| 玩法 | 说明 |
| --- | --- |
| 城市怪兽 Boss | 系统或运营投放，限时；去运动（轨迹经过怪兽范围）或投入能量合击造成伤害；实时血量；击败按伤害排名掉落；到期未击败返还少量能量；怪兽在场时范围内领地每日产能减半 |
| 能量宝箱 | 每日刷新；跑步轨迹经过宝箱范围自动开启，也可以到附近手动开；深夜（23:00–05:00）不刷新 |
| 守地挑战 | 领地被攻击（削弱或被切走一部分）后，主人在 24 小时内跑一圈经过这块地就能加固：守卫值加上本次运动能量 |
| 赛季 | 2 个月一季；按赛季内新圈到的面积定段位（青铜 → 钻石，每段 III/II/I）和排名；赛季任务每周刷新；成就奖牌带进度；赛季结束按最终段位发赛季奖牌，不清空建筑和图鉴 |
| 城区联赛 | 每周一 00:00 结算；同城区的跑团按本周成员新圈面积排名 |
| 限时活动 | 运营配置：配速挑战、夜跑专场、距离挑战；运动结算时自动判定完成 |
| 城市定向 | 运营配置一条有序打卡点路线，可以分多次跑，按顺序经过每个点，全部到达即完成 |
| 跑步伙伴养成 | 孵化后的伙伴有等级和经验：陪跑每 100 m 加经验，也可以喂能量；伙伴仍然不提供对抗加成 |
| 跑团接力 | 团长发起，N 棒，每位成员一次运动跑满单棒距离算一棒，限时完成，全员得奖励 |
| 实时推送 | WebSocket：怪兽血量、自己领地被攻击、合击召集 |

## App · 城市怪兽

### GET /v1/bosses/{id} → Boss
```json
{
  "id": 3, "kind": "sofa", "name": "沙发怪", "level": 12, "description": "它代表「懒得动」……",
  "location_name": "滨江公园一带", "center": {..}, "radius_m": 1000,
  "hp": 3800, "hp_max": 10000, "status": "active | defeated | expired",
  "spawned_at": "...", "expires_at": "...", "defeated_at": null,
  "occupied_territories": 3, "effect_text": "范围内领地每日能量产出减半",
  "damage_rules": [ { "sport": "run", "label": "跑步", "per": 1, "unit": "km", "damage": 100 } ],
  "strike": { "cost": 100, "damage": 40, "cooldown_s": 30, "available_in_s": 0 },
  "participants": 23,
  "rank": [ { "rank": 1, "user": { "id": 1, "nickname": "...", "avatar_url": null }, "damage": 1200 } ],
  "me": { "damage": 530, "rank": 5, "engaged_until": null },
  "drops": [ { "item": "banner", "kind": "role", "name": "旗手卡", "percent": 35 } ],
  "my_rewards": [ { "item": "banner", "kind": "role", "name": "旗手卡", "converted_energy": null } ]
}
```
`rank` 最多 20 名。`my_rewards` 只在 `defeated` / `expired` 后有值；已经有的角色卡重复掉落时折算为能量（`converted_energy`）。

### POST /v1/bosses/{id}/strike
`{"lat":..,"lng":..}` → `{"damage":44,"combo_pct":10,"energy":1180,"boss":{"id":3,"hp":3756,"status":"active"}}`
- 必须在怪兽范围内（`radius_m`），每次消耗 `strike_cost` 能量，造成 `strike_damage` 伤害。
- 加成：拥有旗手且在跑团里 +10%；同一跑团成员在 `combo_window_s` 内也出手过，每人 +`combo_pct`%，最多 +`combo_max_pct`%。
- 服务端每 30 秒发一次 ping，客户端不需要回复；75 秒内什么都没收到可视为断线重连。
- 每次出手会给同跑团成员推送合击召集（WebSocket + 站内消息，5 分钟内最多一条）。
- 错误：`out_of_range` 403、`not_enough_energy` 403、`cooldown` 429（带 `retry_after_s`）、`boss_not_active` 409。

### POST /v1/bosses/{id}/engage
`{"lat":..,"lng":..}` → `{"engaged_until":"..."}`。在范围内点「去运动出战」。之后 `engage_h` 小时内的**居家运动**（跳绳、力量、瑜伽、HIIT）也会对它造成伤害；GPS 运动只要轨迹进入范围就自动计算，不需要 engage。

### 伤害计算
GPS 运动：轨迹落在范围内的距离 × 规则（例如跑步每 km 100）。居家运动：数量 × 规则。合击：见上。怪兽血量归零的那次运动或合击把它击败。

### 击败与到期
- 击败：每位参与者掷 1 次掉落表，伤害前 `top_extra_rolls` 名多掷 1 次；掉落「energy」得 `drop_energy` 能量；角色、图纸、伙伴蛋进图鉴（重复的角色或图纸折算 50 能量）。全体参与者收到站内消息。
- 到期未击败：每位参与者返还合击花费的 `expire_refund_pct`%。
- 掉落用可复现的随机数（怪兽 id + 用户 id），管理端可审计。

## App · 宝箱

### POST /v1/chests/{id}/open
`{"lat":..,"lng":..}` → `{"energy":40,"bonus":false}`。需在 `radius_m` 内。药剂师（宝箱额外掉落 +5%）有概率 `bonus=true` 能量翻倍。每个宝箱每人只能开一次。错误：`out_of_range`、`already_opened`、`chest_expired`。

## App · 守地挑战

`GET /v1/territories/{id}` 新增 `"defense": {"deadline":"...","attacked_by":{"id":..,"nickname":".."}} | null`。主人在期限内的运动轨迹经过这块领地（与圈地无关，只要穿过）即加固：守卫值 += 本次运动能量（不超过 `max_guard`），结算里出现在 `defended`。

## App · 伙伴养成与接力

- 图鉴 `companions[]` 新增 `level`、`exp`、`exp_to_next`、`meters`（陪跑总米数）。
- `POST /v1/codex/companions/{key}/feed` → Codex。消耗 `feed_cost` 能量，`+feed_exp` 经验。错误：`companion_not_hatched`、`not_enough_energy`。
- 图鉴新增 `monsters: [{ "key": "sofa", "name": "沙发怪", "strikes": 12, "defeats": 2, "best_rank": 3, "seen": true }]`，`progress.monsters` 如 `"2/4"`。
- `POST /v1/crews/{id}/relays`（团长）`{"legs":6,"leg_km":3}` → Relay；已有进行中的接力返回 409 `relay_running`。
- `GET /v1/crews/{id}/relays/current` → Relay 或 `null`
```json
{ "id": 4, "legs": 6, "leg_km": 3, "status": "running | completed | expired", "started_at": "...", "expires_at": "...",
  "runs": [ { "leg": 1, "user": {..}, "activity_id": 88, "distance_m": 3200, "at": "..." } ] }
```
每位成员最多跑一棒；单次 GPS 运动距离 ≥ `leg_km` 才算。

## 实时：WebSocket

`GET /v1/ws?token=<access_token>`（升级为 WebSocket）。客户端发：
`{"sub":"boss:3"}` / `{"unsub":"boss:3"}`。服务端发：
- `{"type":"boss","boss":{"id":3,"hp":3756,"status":"active"},"by":{"id":1,"nickname":".."},"damage":44}`
- `{"type":"territory_attacked","territory_id":12,"captured":false,"guard_after":20}`（只发给领地主人）
- `{"type":"rally","boss_id":3,"by":{"id":1,"nickname":".."}}`（只发给同跑团成员）
- `{"type":"ping"}` 每 30 秒一次。

断线后客户端用 `GET /v1/bosses/{id}` 补状态。

## 管理端

| 接口 | 说明 |
| --- | --- |
| `GET /admin/v1/bosses?status=active|defeated|expired&page=` | 列表：kind、name、level、location_name、hp/hp_max、participants、spawned_by（管理员 id 或 null=系统）、spawned_at、expires_at |
| `POST /admin/v1/bosses` | `{kind, lat, lng, location_name, level, hp, radius_m, duration_h}`（后四项可省略，用配置默认值）→ Boss；深夜时段也允许运营手动投放 |
| `GET /admin/v1/bosses/{id}` | 同 App 的 Boss，`rank` 返回全部参与者，加 `rewards: [{user, rank, damage, items, energy}]` |
| `POST /admin/v1/bosses/{id}/end` | 提前结束（按到期处理） |
| `GET /admin/v1/chests?status=active|expired|removed&page=` | 列表：`{id, center, radius_m, expires_at, energy_min, energy_max, opens（开启人数）, source, status}`；每个宝箱每人可开一次，所以没有「领完」状态 |
| `POST /admin/v1/chests` | `{lat, lng, energy_min, energy_max, duration_h, radius_m}` |
| `POST /admin/v1/chests/scatter` | `{bbox: "minLng,minLat,maxLng,maxLat", count, duration_h}` → `{placed}`：在 bbox 内近 30 天跑者常经过的轨迹点上随机撒 |
| `DELETE /admin/v1/chests/{id}` | 下架 |
| `GET /admin/v1/map/objects?bbox=` | 同 App，不按用户过滤 |
| `GET/POST /admin/v1/seasons`，`PATCH /admin/v1/seasons/{id}`，`POST /admin/v1/seasons/{id}/settle` | 赛季：`{name, starts_at, ends_at}`，列表项另有 `days_left`、`settled_at`；时间不能和其他赛季重叠（409 `season_overlap`）；结算后不可修改。增改和结算都返回完整列表 `{items}` |
| `GET/POST /admin/v1/campaigns`，`PATCH /admin/v1/campaigns/{id}`，`DELETE` | 限时活动：`{title, type, description, rules, starts_at, ends_at, reward_energy, reward_medal_name}`；夜跑时段 0–23 且 from < to（不跨零点）；`DELETE` 只能删未开始的；增改返回完整列表 `{items}` |
| `GET/POST /admin/v1/routes`，`PATCH /admin/v1/routes/{id}`，`DELETE` | 定向路线：`{name, description, checkpoints:[{name, lat, lng, radius_m}], reward_energy, starts_at, ends_at}`，2–12 个点，半径 10–500 m；列表项另有 `finishers`（完成人数）；增改返回完整列表 `{items}` |
| `GET /admin/v1/league?district=&week_start=` | 联赛榜（含历史周） |
| `GET /admin/v1/districts` | `{"items":[{"name":"徐汇区","crews":12}]}`：有跑团的城区，供联赛选择 |

后台任务：每小时检查自动投放怪兽（活跃怪兽少于 `auto_spawn_max`、非深夜，投在近 24 小时运动最集中的地方）；每天 06:00 刷新宝箱；怪兽到期处理；赛季到期自动结算；每周一 00:00 结算城区联赛；接力到期。
