# 圈圈 Loopland · 真实服务接入清单

代码已全部接好，这份清单列出每家服务要去哪里申请、需要准备什么、拿到的东西填到哪里。

- **第三方服务的 Key（后端用的）**：在管理端「系统配置」页面填写，加密存库，保存即生效，可以逐项「测试连接」（接口见 `docs/api/系统配置.md`，只有 admin 角色能看）。下表「填到哪里」写的「管理端 · 服务 · 字段」就是这个页面。
- **后端系统级配置**：`server/config.prod.example.yaml`（端口、数据库、Redis、JWT、数据加密密钥、公网地址；密钥用 `*_file` 指向密钥文件）。
- **App 配置**：`app/config/app.yaml`（统一的域名/API/SDK Key 配置，真实值写在被 git 忽略的 `app/config/app.local.yaml`），用 `dart run tool/gen_config.dart --profile prod` 生成各平台文件，详见 `app/README.md`。
- **管理端配置**：`admin/config.yaml`（域名、端口、API 前缀、高德 Key）。
- 密钥只放在服务器的密钥管理（阿里云 KMS / Kubernetes Secret）和本地被 git 忽略的文件里，**不要提交到仓库，也不要发到聊天里**。

## 一、先办的主体资质（所有渠道都要）

| 事项 | 说明 |
| --- | --- |
| 公司营业执照、对公账户 | 微信支付、支付宝、Apple 开发者（公司账号）都要求企业主体 |

| App 备案 | 上架国内应用商店前必须完成（工信部 App 备案） |
| 软件著作权 | 各安卓商店上架常要求 |

## 三、上线前验证顺序

1. 后端配好 `config.yaml`、在管理端「系统配置」填好各服务并逐项点「测试连接」，再在服务器上运行自检（读取的是同一份生效配置），全部通过再继续：
   ```bash
   loopland-doctor
   ```
   需要真发一条短信时加 `-sms-to 你的手机号`；需要真跑一次实名核验（收费）时加 `-realname '姓名,身份证号'`；需要发测试邮件时加 `-mail-to 邮箱`。
2. 支付宝沙箱 + 微信支付 1 分钱测试套餐（在管理端临时把某套餐首期价改成 1 分）各走一遍：下单 → 支付 → 回调 → 会员生效 → 管理端退款 → 权益收回。测试完改回价格。
3. iOS 用沙箱账号：购买连续包月 → 会员生效 → 在沙箱里取消订阅 → 收到 Apple 通知后自动续费状态变为关闭。
4. 安卓真机：一键登录（关掉 Wi-Fi 用流量）、微信登录、跑一圈圈地、锁屏继续记录。
5. 暂时不上的服务在管理端「系统配置」里关掉「启用」，App 会自动隐藏对应入口（`GET /v1/config/features`），不用重启。

## 四、还需要商务开通的

- 微信「委托代扣」、支付宝「周期扣款」：开通前，安卓的连续包月到期时会提醒用户手动续费；开通后需要在首次购买时加签约流程（代码里 `Charge` 接口已预留）。
- 阿里云号码认证、短信、实人认证都按量计费，建议在阿里云设置费用预警。
