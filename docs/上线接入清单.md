# 圈圈 Loopland · 真实服务接入清单

代码已全部接好，这份清单列出每家服务要去哪里申请、需要准备什么、拿到的东西填到哪里。

- 后端配置：`server/config.prod.example.yaml`（正式环境模板，所有系统级配置收口在一个 YAML 里；密钥用 `*_file` 指向密钥文件）
- App 配置模板：`app/config/*.json.example`、`app/android/*.properties.example`、`app/ios/Flutter/*.xcconfig.example`（详见 `app/README.md`「接入真实 SDK」）
- 密钥只放在服务器的密钥管理（阿里云 KMS / Kubernetes Secret）和本地被 git 忽略的文件里，**不要提交到仓库，也不要发到聊天里**。

## 一、先办的主体资质（所有渠道都要）

| 事项 | 说明 |
| --- | --- |
| 公司营业执照、对公账户 | 微信支付、支付宝、Apple 开发者（公司账号）都要求企业主体 |
| 域名 + ICP 备案 | 支付回调地址和 iOS 通用链接必须是备案过的 https 域名，例如 `api.xxx.com` |
| App 备案 | 上架国内应用商店前必须完成（工信部 App 备案） |
| 软件著作权 | 各安卓商店上架常要求 |

## 二、逐个服务

### 1. 阿里云（短信、验证码、一键登录、实名）

| 产品 | 控制台里要做的 | 拿到什么 | 填到哪里 |
| --- | --- | --- | --- |
| RAM 子账号 | 新建子账号，只开 OpenAPI 访问，授权短信、号码认证、验证码、实人认证 | AccessKey ID / Secret | 后端 `aliyun.access_key_id`、`aliyun.access_key_secret_file` |
| 短信服务 | 申请签名「圈圈」，申请验证码模板（内容含 `${code}`），等审核 | 签名名称、模板 CODE | `ALIYUN_SMS_SIGN_NAME`、`ALIYUN_SMS_TEMPLATE_CODE` |
| 验证码 2.0 | 新建场景（App / H5），绑定 App 包名 | 场景 ID、身份标（prefix） | 后端 `ALIYUN_CAPTCHA_SCENE_ID`；App `ALIYUN_CAPTCHA_SCENE_ID`、`ALIYUN_CAPTCHA_PREFIX` |
| 号码认证（一键登录） | 分别为 Android（包名 + 签名 MD5）和 iOS（Bundle ID）创建认证方案 | 两个方案秘钥 | App `ALIYUN_AUTH_SECRET_ANDROID` / `ALIYUN_AUTH_SECRET_IOS`；后端复用 AccessKey |
| 实人认证 · 身份证二要素 | 开通「身份证二要素核验」 | —— | 复用 AccessKey；后端以 md5 模式提交，不发明文出生日期 |

### 2. 微信

| 平台 | 要做的 | 拿到什么 | 填到哪里 |
| --- | --- | --- | --- |
| 微信开放平台 | 开发者资质认证（收费）；创建「移动应用」，填包名、应用签名（release 签名 MD5，小写无冒号）、iOS Bundle ID 和 Universal Link | AppID、AppSecret | 后端 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`；App `WECHAT_APP_ID`、`WECHAT_UNIVERSAL_LINK` |
| 服务器 IP 白名单 | 开放平台里把后端出口 IP 加入白名单 | —— | —— |
| 微信支付商户平台 | 申请商户号，开通 APP 支付，在开放平台把移动应用与商户号关联 | 商户号 | `WECHAT_MCH_ID` |
| 商户 API 证书 | 下载 API 证书 | `apiclient_key.pem`、证书序列号 | `WECHAT_MCH_PRIVATE_KEY(_FILE)`、`WECHAT_MCH_SERIAL_NO` |
| APIv3 密钥 | 设置 32 位 APIv3 密钥 | 密钥 | `WECHAT_APIV3_KEY` |
| 微信支付公钥 | 「API 安全」里申请微信支付公钥 | `pub_key.pem`、公钥 ID | `WECHAT_PAY_PUBLIC_KEY(_FILE)`、`WECHAT_PAY_PUBLIC_KEY_ID` |
| 通用链接 | 在域名根目录放 `apple-app-site-association`（见 App README） | —— | iOS Associated Domains |

回调地址不用在后台填，下单时自动带上 `https://你的域名/v1/pay/notify/wechat`。

### 3. 支付宝

| 要做的 | 拿到什么 | 填到哪里 |
| --- | --- | --- |
| 支付宝开放平台创建「移动应用」，签约「APP 支付」 | AppID | 后端 `ALIPAY_APP_ID` |
| 用支付宝密钥工具生成 RSA2 密钥，上传应用公钥，下载**支付宝公钥** | 应用私钥、支付宝公钥 | `ALIPAY_PRIVATE_KEY(_FILE)`、`ALIPAY_PUBLIC_KEY(_FILE)` |
| 先用沙箱联调 | 沙箱 AppID 和密钥 | 同上，再加 `ALIPAY_SANDBOX=1` |
| iOS 回调 | 自定义 URL Scheme（如 `loopland-alipay`） | App `ALIPAY_URL_SCHEME` |

回调地址自动带上 `https://你的域名/v1/pay/notify/alipay`。

## 三、上线前验证顺序

1. 后端配好变量后运行自检，全部通过再继续：
   ```bash
   loopland-doctor
   ```
   需要真发一条短信时加 `-sms-to 你的手机号`；需要真跑一次实名核验（收费）时加 `-realname '姓名,身份证号'`。
2. 支付宝沙箱 + 微信支付 1 分钱测试套餐（在管理端临时把某套餐首期价改成 1 分）各走一遍：下单 → 支付 → 回调 → 会员生效 → 管理端退款 → 权益收回。测试完改回价格。
3. iOS 用沙箱账号：购买连续包月 → 会员生效 → 在沙箱里取消订阅 → 收到 Apple 通知后自动续费状态变为关闭。
4. 安卓真机：一键登录（关掉 Wi-Fi 用流量）、微信登录、跑一圈圈地、锁屏继续记录。
5. 暂时不上的功能写进 `LOOPLAND_DISABLE`，App 会自动隐藏对应入口（`GET /v1/config/features`）。

## 四、还需要商务开通的

- 微信「委托代扣」、支付宝「周期扣款」：开通前，安卓的连续包月到期时会提醒用户手动续费；开通后需要在首次购买时加签约流程（代码里 `Charge` 接口已预留）。
- 阿里云号码认证、短信、实人认证都按量计费，建议在阿里云设置费用预警。
