# 圈圈 Loopland · 音频素材清单（语音 + 音效 + 角色声音）

这份清单给素材生成用：按「文件名」生成，放进 `app/assets/audio/` 对应目录交回，App 按文件名接入。
清单里每一条都对应 App 里一个具体时刻，没列的先不做。

---

## 一、整体思路

| 层 | 用在哪 | 怎么做 |
|---|---|---|
| **语音播报**（圈圈的声音） | 跑步中、AI 跟练、结算 | 固定台词**预先录好**（有情绪、有个性）；带数字的播报（距离、配速、用时）先用**系统语音合成**拼出来，以后再换成录好的数字片段 |
| **音效** | 点按、切换、圈地、开宝箱、升级等 | 0.05–1.5 秒的短音效，统一一套「轻快、带一点弹性和颗粒感」的风格 |
| **角色声音** | 点怪兽、点伙伴、打怪、击败 | 不说话的「叫声」（嘟囔、啾、咕噜），每个角色 2–3 个变体随机播，避免听腻 |
| **震动** | 和关键音效同步 | 手机自带，不需要素材（圈地成功、开宝箱、长按结束等配一下轻震） |

**播放规则（我来实现）**
- 设置里分开三个开关：「语音播报」「音效」「角色声音」，外加音量。系统静音（iPhone 静音键）时只震动不出声。
- 跑步中的语音**混在用户的音乐里**（播报时把音乐压低，播完恢复），不打断音乐和播客。
- 同一时刻只播一条语音，按优先级排队：安全提示 > 圈地成功 > 打怪 > 公里播报 > 其他；同类提示最短间隔 20 秒，防止啰嗦。
- 可选「只在戴耳机时播报」。

## 二、技术规格（生成时请统一）

| 项 | 语音 | 音效 / 角色声音 |
|---|---|---|
| 格式 | `.m4a`（AAC），也可以先给 `.wav` 我来转 | 同左 |
| 采样率 / 声道 | 44.1 kHz，单声道 | 44.1 kHz，单声道 |
| 码率 | 96 kbps | 128 kbps |
| 响度 | 约 -16 LUFS，峰值不超过 -1 dBTP | UI 音效 -20 LUFS；事件音效 -16 LUFS |
| 首尾静音 | 开头 ≤ 20 毫秒，结尾 ≤ 100 毫秒（裁掉多余静音） | 开头 ≤ 5 毫秒 |
| 时长 | 一句 ≤ 3 秒（最长 4 秒） | UI 0.05–0.3 秒；事件 0.4–1.5 秒 |
| 版权 | 生成工具需允许**商用**（上架 App），保留生成记录 | 同左 |

**文件命名**：`<目录>/<编号>.m4a`，有变体时加 `_1` `_2` `_3`，如 `sfx/ui_tap_1.m4a`。

## 三、圈圈的声音人设

- **是谁**：App 里的 AI 助手「圈圈」，也是跑步时陪你的「跑友」。
- **声音**：年轻、元气、偏中性（略偏女声或少年音都可以），**像身边一起跑的朋友，不像导航播报**；语速比正常说话略快，句尾上扬、带笑意；激动时可以喊，但不尖。
- **说话方式**：短句、口语、少用敬语；夸人要具体（「这圈画得真圆！」而不是「做得很好」）。
- **一致性**：全部台词用**同一个声音、同一套参数**生成；建议先生成 5 句试听样本给我，我们定下来再批量生成。

生成工具描述可以参考：
> 年轻有活力的中文普通话声音，像一起夜跑的朋友在耳边说话，轻快、带笑意、语速略快，句尾自然上扬；激动时声音会提高但不刺耳。

## 七、建议的生成顺序

1. **第一批（跑步核心体验）**：圈圈 5 句试听样本 → 定下声音后生成 4.1 里标「必需」的台词；音效里的 `ui_tap` `ui_tab` `start_press` `run_tick` `run_go` `run_hold` `run_hold_done` `claim` `chest_open` `energy_gain`；4 个怪兽的 `_tap` `_hit` `_down`。
2. **第二批**：4.1 的「推荐」台词、4.2 跟练、4.3 结算；其余音效；6 个伙伴。
3. **第三批（可选）**：角色卡声音、数字片段（全部换成圈圈的声音播报数字）。

交回时按目录放好即可：

```
app/assets/audio/
  voice/run/      run_go.m4a  run_claim_1.m4a …
  voice/coach/    coach_ready.m4a …
  voice/result/   result_pb.m4a …
  sfx/            ui_tap_1.m4a  claim_1.m4a …
  char/           boss_sofa_tap_1.m4a  pet_gecko_tap_1.m4a …
```

缺的文件不影响使用：App 找不到素材时，语音退回系统语音合成，音效和角色声音就不播。

## 八、接入说明（App）

### 代码在哪

| 文件 | 作用 |
|---|---|
| `app/lib/audio/sound_catalog.dart` | 素材目录：编号 → 文件（`_1/_2/_3` 变体）、通道、台词（缺素材时读给系统语音）、单文件音量补偿 |
| `app/lib/audio/audio_engine.dart` | 播放引擎：三个通道的开关和音量（存在本机）、随机变体（不连续重复）、震动、长按蓄力循环、语音队列 |
| `app/lib/audio/audioplayers_backend.dart` | 真正出声：`audioplayers`（Android / iOS / 网页）+ 系统语音合成（`flutter_tts`） |
| `app/lib/audio/recording_backend.dart` | 测试用：只记录要播什么，不出声；`flutter test` 下默认用静音后端 |
| `app/lib/audio/run_sounds.dart` | 跑步中的时机（倒计时、圈地、闭合提示、公里播报、GPS、怪兽、宝箱、长按结束） |
| `app/lib/audio/settlement_sounds.dart` | 结算页的音效和语音 |
| `app/lib/features/me/sound_settings.dart` | 设置 →「声音」：三个开关、音量、试听 |

页面里用 `ref.read(audioProvider).play(Sounds.xxx)`（音效 / 角色声音）、`.say(Sounds.xxx, priority: …)`（语音）、`.sayText('…', kind: …)`（带数字的系统语音）、`.haptic(HapticKind.medium)`；没有 `ref` 的地方用 `playSound(context, Sounds.xxx)`。

### 播放规则（实现）

- 三个通道各自开关 + 音量，存在本机（`shared_preferences`，键 `audio_settings`），不跟账号同步。试听不受开关限制。
- 语音一次只播一条，按优先级排队：倒计时 > 安全提示（GPS）> 圈地 > 打怪 > 公里播报 > 其他；同一类 20 秒内不重复（倒计时除外）；排队太久的低优先级提示直接丢掉（其他 8 秒、公里 20 秒、打怪 / 圈地 15 秒、安全 30 秒），最多排 4 条。
- 录好的台词找不到文件时，用系统语音读台词原文；音效、角色声音找不到就不播。
- 语音播报时把用户的音乐压低（Android 申请 `MAY_DUCK` 焦点；iOS 播报期间切到 `playback + mixWithOthers + duckOthers`，播完切回 `ambient`），不打断音乐。音效和角色声音不抢焦点、和音乐混在一起；iOS 用 `ambient`，静音键打开时不出声，只震动。
- iOS 已在 `Info.plist` 的 `UIBackgroundModes` 加 `audio`，锁屏跑步时也能播报。
- 「只在戴耳机时播报」暂未做：判断耳机需要原生代码（`AVAudioSession.currentRoute` / `AudioManager.getDevices`），播放插件不提供。
- 任何播放失败都只打日志，不影响页面。网页版第一次出声要在用户点过页面之后（浏览器自动播放限制）。

### 加一个声音

1. 文件放进 `app/assets/audio/<目录>/`（目录已在 `pubspec.yaml` 注册；新目录要加一行）。
2. 在 `sound_catalog.dart` 的 `Sounds` 里加一项（有变体写 `variants:`），并加进 `Sounds.all`。语音要写台词。
3. 在对应页面调用 `play` / `say`。`test/audio/audio_engine_test.dart` 会检查「目录里的每个文件都在、每个文件都登记了」。

### 单文件音量补偿

处理报告里这几个文件偏小 2–4 dB，播放时放大。音效和角色声音整体比满刻度低 2.5 dB（×0.75）留出余量，所以音量在 100% 时最多能补到 +2.5 dB，音量调低后按表里的值补足。

| 文件 | 补偿 |
|---|---|
| `sfx/boss_hit_1` | +3 dB |
| `char/boss_bat_tap_2` | +2 dB |
| `char/boss_smog_hit_2` | +3 dB |

重新生成、响度正常后，删掉 `sound_catalog.dart` 里对应的 `gainsDb` 即可。
