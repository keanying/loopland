# 圈圈 Loopland · 本地启动（Linux / macOS / Windows）

三端：**后端**（Go）、**管理端**（React）、**App**（Flutter）。数据库是 PostgreSQL 16 + PostGIS 3，缓存是 Redis 7。

## 配置文件（全部系统级配置都在这里）

| 端 | 配置文件（已提交，本地开发默认值） | 本机覆盖（不提交） | 正式环境 |
| --- | --- | --- | --- |
| 后端 | `server/config.yaml` | 同名环境变量覆盖单项 | 复制 `server/config.prod.example.yaml` 到服务器，用 `LOOPLAND_CONFIG=路径` 指定；密钥用 `*_file` 指向密钥文件 |
| 管理端 | `admin/config.yaml`（端口、后端地址、API 前缀、高德 Key 等） | `admin/config.local.yaml` | 构建时用的同一套文件，见 `admin/README.md` |
| App | `app/config/app.yaml`（按 dev / prod 分档：API 域名、协议链接、各 SDK 的 Key） | `app/config/app.local.yaml` | `prod` 档；运行 `dart run tool/gen_config.dart --profile prod` 生成各端文件 |

读取顺序都是：**内置默认值 → 配置文件 → 本机覆盖 / 环境变量**，后者优先。配置文件里字段名写错会直接报错，不会悄悄用默认值。

## 一、准备工具

| 工具 | 版本 | Linux | Windows |
| --- | --- | --- | --- |
| Git | 任意 | 发行版自带 | [git-scm.com](https://git-scm.com/download/win)，安装时选「Checkout as-is, commit Unix-style」或保持默认均可（仓库有 `.gitattributes`） |
| Go | ≥ 1.26 | [go.dev/dl](https://go.dev/dl/) | 同左，下载 `.msi` |
| Node.js | 22 LTS | nvm 或发行版包 | [nodejs.org](https://nodejs.org/) `.msi` |
| Flutter | 3.50 | [docs.flutter.dev](https://docs.flutter.dev/get-started/install/linux) | [docs.flutter.dev](https://docs.flutter.dev/get-started/install/windows)；Android 开发装 Android Studio |
| Docker | 最新 | Docker Engine + compose 插件 | Docker Desktop（需要开启 WSL2） |

不想装 Docker 时，数据库和缓存可以装在本机：
- Linux：`sudo apt install postgresql-16 postgresql-16-postgis-3 redis-server`
- Windows：PostgreSQL 用 [EDB 安装包](https://www.postgresql.org/download/windows/)，装完在 Stack Builder 里勾选 **PostGIS 3**；Redis 用 [Memurai](https://www.memurai.com/)（Redis 兼容），或在 WSL 里 `sudo apt install redis-server`。
- 然后运行一次 `db-init`（见下文）建用户、库和 PostGIS 扩展。

检查工具是否齐全：

Linux / macOS：
```bash
scripts/dev.sh check
```

Windows（PowerShell）：
```powershell
.\scripts\dev.ps1 check
```

第一次在 Windows 上运行脚本如果提示「禁止运行脚本」，先执行一次：
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 二、最快：Docker 一键启动后端 + 管理端

两个系统命令相同（Windows 在 PowerShell 里执行）：
```bash
docker compose -f deploy/docker-compose.yml up -d --build
```
灌演示数据（6 个用户、圈地、跑团、会员订单、赛季、怪兽、宝箱、定向路线）：
```bash
docker compose -f deploy/docker-compose.yml run --rm seed
```

| 服务 | 地址 |
| --- | --- |
| 后端 API | http://localhost:8080（`/healthz` 健康检查） |
| 管理端 | http://localhost:8000，账号 `admin` / `admin-password-1` |
| PostgreSQL | localhost:5432，`loopland` / `loopland` |
| Redis | localhost:6379 |

停止：`docker compose -f deploy/docker-compose.yml down`（加 `-v` 连数据一起删）。

## 三、本机开发（改代码时用）

脚本在 `scripts/` 下，两个系统命令一一对应：

| 做什么 | Linux / macOS | Windows（PowerShell） |
| --- | --- | --- |
| 启动数据库和缓存（Docker） | `scripts/dev.sh deps` | `.\scripts\dev.ps1 deps` |
| 本机数据库建用户、库、PostGIS（不用 Docker 时） | `scripts/dev.sh db-init` | `.\scripts\dev.ps1 db-init` |
| 启动后端（读 `server/config.yaml`） | `scripts/dev.sh api` | `.\scripts\dev.ps1 api` |
| 灌演示数据 | `scripts/dev.sh seed` | `.\scripts\dev.ps1 seed` |
| 启动管理端（读 `admin/config.yaml`） | `scripts/dev.sh admin` | `.\scripts\dev.ps1 admin` |
| 管理端模拟数据模式（不需要后端） | `scripts/dev.sh admin-mock` | `.\scripts\dev.ps1 admin-mock` |
| 启动 App（读 `app/config/app.yaml`） | `scripts/dev.sh app [设备]` | `.\scripts\dev.ps1 app [设备]` |
| 检查后端配置和第三方服务 | `scripts/dev.sh doctor` | `.\scripts\dev.ps1 doctor` |
| 跑三端全部测试 | `scripts/dev.sh test` | `.\scripts\dev.ps1 test` |
| 一条命令：数据库 + 后端 + 演示数据 + 管理端 | `scripts/dev.sh all` | `.\scripts\dev.ps1 all`（后端在新窗口里运行） |

开发时一般开三个终端：
1. `deps` 后 `api`（后端，http://localhost:8080）
2. `admin`（管理端，默认 http://localhost:5173，请求会代理到后端）
3. `app`（App）

### App 跑在哪

| 设备 | 命令（Linux / Windows 相同，把 `scripts/dev.sh` 换成 `.\scripts\dev.ps1`） | 后端地址 |
| --- | --- | --- |
| Chrome 浏览器（看界面最快，定位用浏览器的） | `scripts/dev.sh app chrome` | localhost |
| Android 模拟器 | `scripts/dev.sh app emulator-5554`（`flutter devices` 查名字） | 脚本自动换成 `10.0.2.2`（模拟器访问电脑的地址） |
| iOS 模拟器（只能 macOS） | `scripts/dev.sh app` | localhost |
| 真机（Android / iPhone） | 在 `app/config/app.local.yaml` 把 `api.base_url` 写成电脑的局域网 IP，例如 `http://192.168.1.10:8080`，手机和电脑连同一个 Wi-Fi | 局域网 IP |

真机还需要放行电脑防火墙的 8080 端口：
- Linux：`sudo ufw allow 8080`
- Windows：在「Windows Defender 防火墙 → 高级设置 → 入站规则」新建规则放行 TCP 8080，或以管理员身份运行：
  ```powershell
  New-NetFirewallRule -DisplayName "Loopland API" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
  ```

dev 模式下的测试登录方式：短信验证码固定 `000000`；一键登录 token 写 `dev:13800138000`；微信 code 写 `dev:任意id`；Apple token 写 `dev:任意id`；支付可选 `mock` 渠道。

## 四、打包

| 产物 | 命令 | 说明 |
| --- | --- | --- |
| 后端二进制（Linux） | `cd server && go build -o loopland-api ./cmd/loopland-api` | |
| 后端二进制（Windows） | `cd server; go build -o loopland-api.exe ./cmd/loopland-api` | 也可以在 Linux 上交叉编译：`GOOS=windows GOARCH=amd64 go build ...` |
| 后端镜像 | `docker build -t loopland-api server` | 镜像里同时带 `loopland-seed`、`loopland-doctor` |
| 管理端静态文件 | `cd admin && npm ci && npm run build` → `admin/dist/` | 生产用 `deploy/admin.Dockerfile`（nginx，同域代理到后端，含 WebSocket） |
| Android 安装包 | `cd app && dart run tool/gen_config.dart --profile prod && flutter build apk --release --dart-define-from-file=config/prod.json` | 需要 `android/key.properties` 和正式签名文件；缺了会直接失败 |
| iOS 安装包 | 同上换成 `flutter build ipa`，只能在 macOS + Xcode 上 | 需要 Apple 开发者账号 |

## 五、常见问题

- **`go run` 报连不上数据库**：先 `deps`（或确认本机 PostgreSQL 在 5432 端口运行），再看 `server/config.yaml` 的 `database.url`。
- **管理端打开后接口 404 / 502**：后端没启动，或 `admin/config.yaml` 里的后端地址不对。
- **App 在 Android 模拟器里连不上**：用 `scripts/dev.sh app emulator-5554` 让脚本自动换成 `10.0.2.2`，或在 `app.local.yaml` 里写好。
- **Windows 上中文乱码**：脚本是带 BOM 的 UTF-8，PowerShell 5.1 和 7 都能正确显示；如果自己改过脚本，保存时要选「UTF-8 with BOM」。
- **Windows 上端口被占用**：`netstat -ano | findstr :8080` 找到进程号，在任务管理器里结束，或在 `server/config.yaml` 里改 `http.addr`。
